About

A quick read of who I am and what I build.

I'm a deep learning research engineer who builds frontier AI systems from first principles — no high-level wrappers, no black boxes. Every architecture in my portfolio was implemented bottom-up, from attention math to distributed training pipelines.

My recent work spans a 422M DeepSeek-V3 reproduction with MLA, aux-loss-free MoE, and Multi-Token Prediction; a Stable Diffusion 1.x trained from scratch on 2× RTX 5090; a hybrid 415M/868M FusionLLM combining MLA, Gated Delta Net, MoE, and MTP; a PaliGemma-style vision-language model trained end-to-end on a P100; and a 15-phase autonomous ML research platform that reads papers, plans experiments, writes patches, runs training, and iterates.

I care about the full stack — paper comprehension, architectural design, numerical stability, memory engineering, distributed training, and now agentic orchestration. See the GitHub profile README for the canonical list, or jump straight to projects.

LLaMA-3-Lite

515M params · GQA · RoPE · fused SwiGLU · RMSNorm · Flash-Attn 2 · 78% peak-memory cut

From-scratch LLaMA-3-style transformer optimized for single-GPU pretraining. The headline result is a 78% peak-memory reduction (92 GB → 20 GB) through gradient checkpointing, chunked cross-entropy, and disk-backed token caching — enabling 2× batch-size headroom on a single A100 80GB.

  • Chunked cross-entropy cuts logits memory from 50 GB to 0.3 GB
  • Flash Attention 2 + BF16 + gradient checkpointing as the memory stack
  • Disk-backed token cache for datasets that exceed RAM

FusionLLM

415.6M active / 868.6M stored · MLA + Gated Delta Net + MoE + MTP in a 24-layer hybrid

A hybrid LLM pre-training framework fusing MLA, Gated Delta Net (linear-attention sequence mixer), DeepSeek-style MoE, and Multi-Token Prediction into one 24-layer stack. Uses a dual optimizer (NorMuon + CautiousAdamW), WSD + μP LR schedule, and logit softcap.

  • Combines attention (MLA) and linear attention (Gated Delta Net) per layer
  • Dual optimizer: NorMuon for matrix params, CautiousAdamW for the rest
  • Architecture complete; 8.31B-token pre-training pipeline ready on a single A100 80GB
